\begin{abstract}
We classify self-reported heart disease in the 2015 BRFSS survey using
six numerical methods and a NumPy gradient-boosted tree ensemble. The
selected GBDT improves validation F1 from 0.4386 for logistic
regression to 0.4462. On the test set, logistic regression scores
0.449 F1 and GBDT scores 0.454.
\end{abstract}

\section{Introduction}

We classify self-reported coronary heart disease or heart attack
(\texttt{\_MICHD}) in the 2015 Behavioral Risk Factor Surveillance System
(BRFSS)~\cite{cdc2015}. The course release contains 328,135 labeled
respondents, 109,379 unlabeled test respondents, and 321 predictors
covering demographics, behavior, health conditions, and healthcare use.

This dataset mixes numeric quantities, categorical answer codes, and
structured missingness. For example, \texttt{PHYSHLTH}=88 means zero days,
while 77 and 99 mean an unknown or refused answer. Codebook-based rules drop
14 survey-design variables, two duplicate variables, and 14 raw mixed-unit
variables with computed replacements; they also convert units and fill
numeric values implied by skipped questions. This leaves 56 numeric and 235
categorical predictors. Unknown and refused categorical answers remain
separate categories. Only 8.83\% of training labels are positive.

We compare numerical baselines with neural networks and gradient-boosted
decision trees (GBDT), which capture nonlinear interactions and learn
how to route missing answers~\cite{chen2016xgboost,ke2017lightgbm}.

\section{Methods}

\subsection{Linear baselines}
We implement the six methods required by the project as linear
baselines. Let $X$ include an intercept, let $y\in\{0,1\}^N$, and
write $z=Xw$. The methods minimize either squared error or logistic
loss:
\begin{align}
 L_{\mathrm{MSE}}(w)&=\frac{\lVert Xw-y\rVert_2^2}{2N},\\
 L_{\mathrm{log}}(w)&=\frac1N\sum_{i=1}^{N}
       \bigl[\log(1+e^{z_i})-y_i z_i\bigr].
\end{align}

Gradient descent (GD) updates $w\leftarrow w-\gamma\nabla L(w)$;
stochastic GD (SGD) uses one sampled row per update. Least squares uses a
pseudoinverse of $X^\top X$, which is singular for our one-hot design;
ridge adds a regularizer $\lambda\lVert w\rVert_2^2$ and solves
$(X^\top X+2N\lambda I)w=X^\top y$. The other two methods minimize logistic loss by GD, with or without
the same $L_2$ penalty.

In the experiments, MSE GD uses 100 steps at $\gamma=0.02$ and SGD
uses $10^6$ single-row steps at $\gamma=5\cdot10^{-6}$. Both logistic
methods use 300 steps at $\gamma=0.1$; ridge and regularized logistic
regression use $\lambda=10^{-3}$.

\subsection{Neural networks}
As a capacity check, we average five NumPy MLPs with ReLU widths 512/256,
dropout 0.3, batch size 512, and AdamW updates~\cite{loshchilov2019adamw} (initial rate $10^{-3}$,
weight decay $10^{-5}$). Training runs for two epochs with cosine rate
decay, selecting checkpoints on an inner 10\% holdout. Numeric inputs use
16-bin piecewise-linear encoding; categorical inputs are one-hot encoded.

\subsection{Gradient-Boosted Decision Trees (GBDT)}
Starting from training log-odds, GBDT adds trees
$F_{t+1}(x)=F_t(x)+\eta f_t(x)$ to reduce logistic
loss~\cite{friedman2001greedy}. Our NumPy implementation uses gradients
and Hessians for splits and leaf values~\cite{chen2016xgboost}, with
up to 64 bins per variable for histogram search~\cite{ke2017lightgbm}.
A separate missing bin is routed to maximize loss reduction. We use depth 5, 550
trees, $\eta=0.05$, leaf $L_2$ penalty 10, minimum child Hessian 5,
and row/feature fractions 0.7/0.3; logits from seeds 0--2 are averaged.

\subsection{Data processing}\label{data_proc}

Each fold fits preprocessing on training rows and applies it to
validation rows. Linear models fill
missing numeric values with training medians, add missingness flags,
one-hot encode categories seen at least 30 times, and standardize the
resulting $\sim1{,}530$ columns. GBDT uses the 291 cleaned variables directly.

\subsection{Validation}
All local evaluations split the labeled training set; the organizers
withhold test labels and score uploaded predictions on AIcrowd.
Predicting all negatives gives 91.17\% accuracy but zero F1, motivating
positive-class F1 and threshold-independent ROC AUC. The numerical baselines use five
shuffled folds (seed 42), with each decision threshold fitted on
training scores. The GBDT comparison repeats five folds with split
seeds 42--44; each scored fold uses a threshold chosen from the other
folds' out-of-fold predictions.

\paragraph{Model choice and refinements.}
The five-fold baseline table and the 15-fold model comparison use
different threshold procedures, so their F1 values should be read
within each table. On the 15 shared folds, the selected three-seed GBDT
improves F1 over logistic regression by 0.0077 (corrected 95\% interval
$[0.0038,0.0115]$)~\cite{nadeau2003inference}. The test submissions
score 0.449 F1 for logistic regression and 0.454 for this GBDT.

The MLP achieves 0.4399, close to logistic regression. The feature bag
uses answer counts and target-ordered codes, reaching 0.4474, but its
paired gain over the selected GBDT is only 0.0011 (corrected $t=1.51$).
Other refinements in Table~\ref{tab:advanced} show similarly small gains.
We retain the three-seed GBDT for its documented submission and
reproducible recipe. Selection used the same folds, so these scores
are not fully nested estimates of the complete model search.

\section{Conclusions}
Encoding supports a strong logistic baseline; GBDT provides the main
gain, while further refinements remain uncertain. The final \texttt{run.py}
refits three GBDTs on all labeled rows, averages logits, and applies
threshold 0.2166; its documented AIcrowd F1 is 0.454.

All 773 training respondents answering \texttt{HAREHAB1}, a question
about rehabilitation after an infarction, are positive. This
post-diagnosis signal limits interpretation as prospective clinical
risk prediction.
