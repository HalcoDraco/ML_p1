Dear students,
 
As the deadline for Project 1 is approaching (tomorrow Thursday Oct 29th, 2026 at 16:00 afternoon), here is a quick recap to make sure your submission is OK (all info is already in the project guidelines PDF). Please create a submission in the system early. You can later edit everything as much as you want, until the final deadline.
Report submission
Run a final spell & format check with your agent, and export your .pdf .
Early before the deadline, please head over to the paper submission system and create a submission, listing all your EPFL addresses*. You can edit your submission files anytime later.
Make a new submission, and fill in the form.
Upload your report .pdf and code github link. The link should have the format https://github.com/your-username/your-proj-name/tree/the-last-commit-hash (you can get the link by going to the github webpage and pressing ‘y’)
Add all 3 authors and their official EPFL email address*. Make sure the emails are correct! They will be able to edit the submission.
Make sure your AIcrowd submission ID and username is correct (check for additional spaces and case).
Under Topics, select `Project 1'.
Press submit. Later you will still be able to edit all parts of the submission until the deadline.
AIcrowd Submission
Make sure your run.py (or run.ipynb) script works and submit the results generated with it on AIcrowd.
Select the submission ID generated by your run.py on AIcrowd, under Submissions, to be used as the final submission. You must provide this submission ID in the paper submission system below.
For reproducibility, only select the right submission which is exactly produced by your run.py (or run.ipynb)!
Make sure your run.py consistently generates the same results. (Maybe try do run it on a different computer or VM).
No worries if there are some slight differences due to floating point precision differences in 32b vs 64b computers. But any other sources of differences, such as random number generators, must be taken into account (use a fixed random seed!).
Code Submission
Test your implementations.py to make sure they work. Pull the latest public tests https://github.com/epfml/ML_course/tree/main/projects/project1/grading_tests and run them on the URL that you will submit. You might be prompted your github username and your personal token password (different than your github password, you can create one as described here). Check that all optimization methods (Normal equations, GD, SGD) converge to the correct value.
Check that your README is complete and that the folder you plan to submit is clean.
Github has a 100MB file size limit, which you should not exceed there. Do not include the dataset in the submission but be clear where to put it. If there are strong reasons you must exceed 100MB, then you can use a timestamped external file hosting service and include an external link and instructions in your code, to ensure reproducibility.
*Or your home institution email if you do not have an @epfl.ch email.
If any questions come up, please use the forum, we’ll be online to answer as fast as possible
