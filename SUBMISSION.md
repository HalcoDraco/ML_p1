## Steps in AIcrowd

1. Log into the account/team used for
   [EPFL Machine Learning Project 1](https://www.aicrowd.com/challenges/epfl-machine-learning-project-1).
2. Open **Submissions**. Each evaluated upload has an identifier, score,
   submission time, and associated account. This identifier is what the
   report-submission form requests; it is not a validation-fold number.
3. Identify the upload whose CSV matches the reproducible prediction file.
   If the existing upload cannot be verified, generate `best.csv` with
   `uv run python run.py --jobs 1` and upload that file, within the daily
   five-submission limit.
4. Select that submission as the **one final submission**. Copy its exact
   submission ID and account/team username, with correct case and no extra
   spaces. Record the score actually returned by AIcrowd.
5. If selecting the 0.456 upload, first recover its exact CSV and recipe and
   verify reproduction. The current report and `run.py` describe the earlier
   0.454 recipe. If selecting `best.csv`, retain its actual reported score in
   the report even if the team achieved a higher score in another experiment.

Test labels are hidden. Neither the CSV nor local validation can establish
the test F1 of an unidentified upload. Only AIcrowd supplies that score.
